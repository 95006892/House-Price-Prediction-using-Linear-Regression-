# House Price Prediction System

A mini project that predicts house prices using data structures.

| Feature | Data structure |
|---|---|
| Store house records | Array |
| Predict price (K nearest houses) | Max Heap / KNN |
| List houses by price | Merge Sort |
| Search by price range | Binary Search Tree (BST) |

## Files

- `main.c` - the C program (console menu)
- `index.html` - web demo of the same data structures, written in JavaScript

## Run the C program

```bash
gcc main.c -o house -lm
./house
```

## Run the web demo

Open `index.html` in any browser. No installation needed.
